---

## About THE IT CODE

THE IT CODE develops practical software and workflow automation solutions that help organisations replace manual processes with efficient digital systems.

**Flagship Product:** HealthSync™ – a digital healthcare workflow and information management platform focused on:

- Patient record management
- Appointment & queue management
- Operational reporting and analytics

The long-term vision includes expanding into education (EduSync™), government (GovSync™), and SMEs (BizSync™).

---

## Website Features

- Fully responsive design (desktop + mobile)
- Clean, modern, professional interface
- Sections: Hero, Company, Problem, Solutions, Products, Founder, Impact, Careers, Contact
- Mobile navigation with smooth transitions
- Contact form (ready for backend integration)

- CSS3 (Flexbox & Grid)
- Vanilla JavaScript
